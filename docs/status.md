## 本机测量

最新两次 60 秒完整录制：首帧约 1.1 秒，输出 38 段、约 1800 帧，音画时长偏差约 3–12ms，1080p 导出约 6.08–6.58 倍实时，含原生进程工作集约 938–1001.4MiB。报告为 dist/verify/perf-result.json 和 perf-60s-first.json。

完整链路实际采集约 28.75–29.65fps，采集帧缺失约 1.17%–4.16%，仍高于 0.5% 的验收目标，因此性能探针明确返回失败，不能把输出补帧后时间槽完整当作采集达标。第二次测试期间还启动了桌面点击验证工具，结果包含此系统负载。原生动态图源对照为独立的 dist/verify/capture-performance.json；targetMet 单独报告各帧率目标，ok 只表示内容/尺寸/退出检查通过。

历史 20 秒样本：首帧约 1466ms，音画时长偏差约 2ms，13 段，Electron 工作集约 892.4MiB；该旧口径漏算原生进程，不能与当前完整口径直接相减。

成片会重复上一帧补齐时间槽，输出帧数完整不等于每一帧都被采集。短样本、静态桌面和输出 60 FPS 均不能作为实时 60 帧采集达标证据。

物理摄像头探针枚举到 3 个设备，但打开设备被 Windows 拒绝权限；该项失败单独记录于 dist/verify/camera-result.json，不计作物理设备通过。

本批另用桌面自动化通道尝试真实点击，窗口截图可读，但两次前台激活均报 `failed to activate captured window`，专用探针未收到点击。未改变系统权限设置，真实点击送达仍待正常交互桌面验收。

## 仍未完成或未充分验证

- 正常交互桌面的真实点击送达、不同 DPI/多屏/提升权限窗口实测；UI Automation 控件语义识别尚未实现。
- WGC 成功路径真机验收：窗口遮挡、移动缩放、来源关闭、权限变化。现代采集仍经过 JPEG 中转，尚非 GPU 零拷贝。
- 物理摄像头多设备、拔插、驱动延迟、60 分钟同步和内存稳定性；严重编码积压仍可能降级。
- 30/60 FPS 动态源性能，以及含摄像头和原生子进程的完整长期内存目标。
- 背景聚焦虚化、独立入场预设、设备样机外框、贴图、图片/视频背景、独立源裁切。
- 用户场景预设和默认场景、iPhone/iPad 有线采集、多语言、自动更新、代码签名。
- 极端倍速（0.25× / 4×）下真实语音的听感人工复听；极端倍速会放大 WSOLA 的相位瑕疵。
- 模糊/马赛克在 4K 输出与多遮挡同帧时的性能与观感复验；两者仍保留轮廓与色彩，不等于不可恢复。

PrintWindow 对最小化、受保护内容和部分 GPU 窗口有限制。系统声音仍来自整台电脑，未实现单应用音频。M4A、3D 透视、兼容窗口采集、实时音频试听、保持音调的变速和真正的模糊/马赛克滤镜均已实现，不再列为待开发。

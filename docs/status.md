## 本机测量

20 秒样本：首帧约 1466 ms，音画时长偏差约 2 ms，共 13 段，最长段 1.6 秒，1080p 导出约 7.84 倍实时。报告在 dist/verify/perf-result.json。

成片会重复上一帧补齐时间槽，输出帧数完整不等于每一帧都被采集。本次源采集约 12.56 fps，尚未达到动态场景 30/60 fps 的要求。短样本、静态桌面和输出 60 FPS 均不能作为实时 60 帧采集达标证据。

物理摄像头探针枚举到 3 个设备，但打开设备被 Windows 拒绝权限；该项失败单独记录于 dist/verify/camera-result.json，不计作物理设备通过。

## 仍未完成或未充分验证

- 正常交互桌面的真实点击送达、不同 DPI/多屏/提升权限窗口实测；UI Automation 控件语义识别尚未实现。
- WGC 成功路径真机验收：窗口遮挡、移动缩放、来源关闭、权限变化。现代采集仍经过 JPEG 中转，尚非 GPU 零拷贝。
- 物理摄像头多设备、拔插、驱动延迟、60 分钟同步和内存稳定性；严重编码积压仍可能降级。
- 30/60 FPS 动态源性能，以及含摄像头和原生子进程的完整长期内存目标。
- 背景聚焦虚化、独立入场预设、设备样机外框、贴图、图片/视频背景、独立源裁切。
- 用户场景预设和默认场景、iPhone/iPad 有线采集、多语言、自动更新、代码签名。
- 保持音调的变速；当前重采样会改变音高。
- “模糊/马赛克”仍是遮盖样式，没有对源画面执行真正模糊/像素化滤镜。实色确认遮挡可用。

PrintWindow 对最小化、受保护内容和部分 GPU 窗口有限制。系统声音仍来自整台电脑，未实现单应用音频。M4A、3D 透视、兼容窗口采集和实时音频试听已实现，不再列为待开发。

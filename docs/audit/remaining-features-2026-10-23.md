# M4A、3D 运镜、窗口采集、音频试听

此前审计修改已提交为 `ebc5dec` 并推送到 `huihui200739/wincapture-studio` 的 main。本批继续在同一仓库实现以下功能。

| 功能 | 实现与使用入口 | 验证 |
| --- | --- | --- |
| M4A | 导出 → 纯音频；AAC/48 kHz/双声道，应用剪辑、变速、音量和静音。跳过视频解码及编码，先写临时文件，回读校验后改名。 | 0.5 秒输出 13,189 字节，无视频轨，时长/声道/采样率/AAC 检查通过；重新解码得到非静音 PCM；取消时清理临时文件。禁用视频编码器后仍可导出。 |
| 3D 运镜 | 编辑器 → 运镜 → 选择/新建镜头 → 3D 运镜；三轴 ±45°、透视距离、重置。旋转随镜头的缓入缓出变化，屏幕/遮挡/光标一起投影，摄像头与画布标注保持独立。 | 三种画幅投影逆变换测试；真实合成有约 5 万个像素改变，0.5 秒/15 帧 MP4 导出与重新解封装校验通过。成片解码后与预览的 RGB 平均误差小于 2/255，遮挡位置仍正确。白底内部网格暗色接缝像素为 0。 |
| 窗口采集 | 录制设置 → 窗口；原生 HWND 枚举与真实缩略图，开始前再次检查窗口。PrintWindow 采集固定输出尺寸，移动后跟随窗口，缩放后按比例留边。 | 独立测试窗口实际采集 18 帧、有真实颜色；窗口移动/缩放几何更新；关闭窗口后工作进程退出并报告 SOURCE_CLOSED。 |
| 实时试听 | 编辑器播放按钮；旁边的扬声器开关仅控制试听。与导出共用 PCM 混音，按播放头排队；暂停、跳转、工程修改、离开页面取消排队并释放解码器和 AudioContext。 | 真实 WAV 解码后 0.5 倍增益峰值为 0.25，2 倍速的 440 Hz 音调在 0.1 秒内有 88 次过零，静音为零；真实 AudioContext 调度通过。单测覆盖暂停/跳转/异步取消/解码错误。 |

同时修复指针归一化遗漏采集原点、输出档位尺寸与源尺寸混用、多显示器物理坐标换算、窗口移出后的光标隐藏，以及创建目录失败时采集状态未复位的问题。

运行 `npm run check`、`npm run verify:remaining`、`npm run verify:parity`、`npm run verify:ui` 可重现测试。真实编码产物与 JSON 写入 `dist/verify/`，界面截图为 `docs/screenshots/16-m4a-export.png`、`17-motion3d.png`。

最终验收：871 项测试、TypeScript、51 条 IPC 契约、全部界面/三画幅/布局/悬浮条/图标检查通过；真实 12 秒录制（含暂停恢复）输出 8 段、360 帧并可独立解封装；4K/60 FPS 倍速导出回归通过。重新构建 109.17 MB 安装包，包完整性及解压版实际启动检查通过。

目视复验补充：修复透视网格白底细缝及透明阴影重复叠加。显卡路径使用单个 WebGL 透视平面与齐次纹理插值；WebGL 不可用时用软件网格按 alpha 替换合成。白底接缝、半透明网格重复混合的异常像素数均为 0。界面验收使用真实鼠标输入移动播放头，确认截图位于 3D 镜头区间。

限制：窗口采集为 PrintWindow 兼容实现，尚无 WGC；最小化/保护内容及部分 GPU 窗口不可录制。系统声音采集整个系统。变速试听与导出使用重采样，音高会改变。iOS 设备接入、聚焦虚化、样机外框、图片/视频背景、个人预设、时间线缩略图/磁吸、多语言、签名和自动更新仍在后续清单，未标记为完成。

# DogSC 对照审查与完善（2026-10-23）

参考仓库：[laogou717/dogsc](https://github.com/laogou717/dogsc)，读取时 main 为 `567fd6ed3bf113227dcf3e815f87ce60f0b69497`。

对照资料包括 README、仓库文件树，以及 RecorderCore/ExportPolicy、PointerTimelineAlignment、ProjectTimelineRetime 和 DogSCApp/EditorWorkspaceLayout、EditorScenePresets 源码。原项目基于 macOS 14 / Swift；本项目使用 Windows / Electron / GDI / WASAPI，原生采集与 Apple 设备接入不能直接移植。

工作区在开始时已有大量未提交的审计修改。本轮在该状态上继续修改，未重置、提交或覆盖成另一份仓库。下面记录本轮发现及处理，既有审计文件是历史记录，涉及的旧风险应以本报告及当前源码为准。本报告不表示所有平台、设备或输入组合均无缺陷。

## 本轮修复

| 问题 | 修复与可见行为 |
| --- | --- |
| 源画面使用归一化坐标适配时遗漏输出画布的像素宽高比 | 补偿画布比例，横屏、竖屏和方形均保持素材真实比例。此前 16:9 内容会被压扁，预览和成片一起出错。 |
| 真实预览没有读取指针日志，导出有光标、编辑器无光标 | 共享指针查找与源时间映射，预览、教程截图、导出应用同一位置、点击、静止隐藏与校准。 |
| 点击波纹只往回查 96 条事件 | 建立最近点击索引，高频指针采样不会让仍有效的点击反馈消失。 |
| 点击反馈强度滑杆改动未进入场景与绘制器 | 0 真正关闭波纹，其余值改变波纹尺寸。 |
| 多个教程缩略图共用一个“最新请求”编号，互相取消 | 按消费者取消各自的旧请求，保留解码串行化，多个缩略图均可完成。 |
| 解码失败或时间线空隙沿用错误时间的旧画面/摄像头 | 帧缓存需精确匹配，失败与空隙不冒充当前素材；摄像头只在命中其片段时显示。 |
| 分割后左右仍沿用同一关联组 | 新分割片段建立独立关联组，右侧画面、声音和摄像头一起移动，左侧不受影响。兼容旧工程时排除同轨相邻片段。 |
| 移动只检查当前轨道，关联音轨可能与其它片段重叠 | 在领域层规划整个关联组的安全落点；直接命令也拒绝产生关联轨碰撞。 |
| 裁剪允许延长到下一片段或超出关联素材长度 | 命令以快照原子校验，拒绝坏工程并显示具体原因。 |
| 只修改源入点时未同步声音；波纹裁剪只移动当前轨道的后续内容 | 同步关联源时间与时长，波纹位移作用于所有后续轨道，保持对齐。 |
| 步骤高亮仍将源时间当成片时间，部分裁剪后区间消失或横跨无关内容 | 按保留的源片段映射；变速右开终点正确取整；校验不再把保留的源截图误判为超出成片时长。 |
| 录制设置正式模式仍用内置演示桌面和模拟音量 | 来源预览改为实际所选来源快照（可刷新，区域按真实坐标裁取）；录制开始前不伪造音量。摄像头示意仍明确标注、不占用设备。 |
| 选中时间线效果后属性面板不跟随 | 自动切到对应运镜/遮挡/光标页签；选择片段回到片段页。页签支持方向键、Home/End 和正确焦点。 |
| 正式首页空态重复显示“新建录制”，无工程时累计时长显示“不足 1 分钟” | 保留顶部主入口，空态改为引导文字，零时长明确显示“0 分钟”。 |
| 4K/60FPS 编码探测与实际编码参数不一致 | 所有录制/导出编码探测传入真实帧率，让 AVC profile/level 及硬件回退选择一致。发现并修复前，实测硬件配置会在第一帧失败。 |
| verify:record 只读取旧 JSON，且错误地作为 Electron 脚本启动 | 新入口自动构建、运行实际采集探针，再以 Node 独立解封装；缺少结果/零分段明确失败，进程有超时。 |
| UI 验收在窗口被遮挡时可能无限等待 requestAnimationFrame | 验收窗口关闭后台限速，稳定等待带超时，截图保持唤醒。 |

## 补齐的功能与界面

- 导出可选原始素材长边、720p、1080p、1440p、4K，跟随工程/30/60 FPS，以及小体积/均衡/高画质。实际像素与预计体积随设置更新，码率随像素数和帧率调整。横竖和方形沿用项目长边约定；切换画幅仍保持构图。
- 场景预设：工作室、简洁白、落日、海蓝、铺满，带缩略预览、选择态和撤销支持。
- 光标：箭头/圆点、静止 2 秒隐藏、±500ms 时间校准；烧录模式继续避免双光标。
- 主视频 0.25×–4× 播放速度。关联音频与摄像头同速，后续轨道一起衔接；遮挡覆盖时间随媒体变换，动画时长维持输出时钟，步骤保持源时间。音频通过重采样变速，**不保调**。跨越变速边界且未分割的其它轨道会明确要求先分割。
- Ctrl+C / Ctrl+V 效果复制粘贴，Ctrl+Shift+V 仅粘贴同类效果属性；工具栏增加入口，设置页增加快捷键说明。粘贴遮挡需要针对新内容重新确认。

## 与 DogSC 仍有的差距

| 能力 | 当前状态与后续工作 |
| --- | --- |
| 窗口采集 | 后续批次已接入 EnumWindows + PrintWindow 兼容采集及真实缩略图，支持移动/缩放，关闭/最小化会中断并保留已录分段；WGC 仍未接入，部分 GPU/保护窗口不支持。 |
| iPhone / iPad 有线采集 | 原项目依赖 Apple 采集栈；Windows 需要独立设备接入方案。 |
| M4A 纯音频导出 | 后续批次已接通 AAC 音频专用封装、轨道混音、回读校验与取消清理；实测无视频轨、不创建视频编码器。 |
| 屏幕 3D、透视、聚焦虚化、入场动画 | 后续批次已实现三轴旋转、透视距离和缓入缓出，使用预览/视频/教程共用网格合成；聚焦虚化与独立入场预设尚未实现。 |
| 样机外框、贴图、视频/图片背景、独立源裁切 | 未补齐。现有预设为画布装饰预设，不等于原项目完整场景保存系统。 |
| 用户预设保存/默认场景 | 本轮提供内置预设；个人预设持久化及默认场景还需实现。 |
| 时间线视频缩略图、磁性边界吸附 | 音频波形已有；视频缩略图与完整磁吸仍缺少。 |
| 编辑器音频实时试听 | 后续批次已接入真实音轨解码、共享导出混音器及 AudioContext 调度，支持增益/静音/变速、暂停和跳转清理，提供试听开关和失败提示。 |
| 摄像头真实预览与动画 | 录制设置页仍明确为示意图；录制用独立窗口，物理设备仍需在正常权限环境复验。 |
| 多语言、自动更新、签名 | 当前中文界面；无更新服务器和签名证书。 |
| 内存目标 | 原有 1080p 总工作集约 2.1GB 的已知限制仍在；本轮未把编码下沉到原生采集进程。 |

本轮完成可独立验证的修复与增强，没有将以上差距标作已完成。
